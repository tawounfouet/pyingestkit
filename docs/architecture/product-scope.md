# Product scope

## In scope for V0.1

- ingestion job contracts;
- explicit step/pipeline runtime;
- local source ingestion;
- RAW artifact persistence and hashing;
- manifest generation;
- basic quality checks;
- atomic local publication;
- plugin discovery;
- CLI.

## Out of scope

- scheduling;
- distributed execution;
- Celery / Kubernetes worker engines;
- Data Catalog / RBAC;
- AI / agents / RAG;
- web UI;
- business-specific normalisation.
