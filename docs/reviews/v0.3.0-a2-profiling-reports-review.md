## Delivered

- `DatasetProfiler`, `DatasetProfile`, `FieldProfile`;
- exact descriptive row/field/null/distinct metrics;
- stable observed Python types without semantic coercion;
- safe string-length and numeric-range profiling;
- deterministic structural duplicate counting, including nested JSON-like values;
- `QualityReport` in-memory aggregate;
- runtime `reports/validation.json` and `reports/profile.json`;
- additive manifest report references;
- `PROFILE_COMPLETED` and `QUALITY_REPORT_WRITTEN` lifecycle events;
- report references exposed through `pyingest status` / `--json`;
- no profile SQL tables and no schema migration;
- ADR-029, ADR-030 and profiling/quality-report guides;
- demo job pack version aligned to `0.3.0a2` while preserving the V0.2 reference jobs.
