# Technical Review — PyIngestKit V0.4.0-a1 Dataset Fingerprints + Diff Engine

## Scope

Alpha 1 introduces only deterministic Dataset identity and pure in-memory comparison. It does not add snapshots, version registry, replay, publication pointers, diff metadata tables or automatic runtime diff computation.

## Delivered

- canonical value codec v1;
- `DatasetFingerprintPolicy`, `DatasetFingerprint`, `DatasetFingerprinter`;
- `DiffPolicy`, `DiffKind`, `DiffEntry`, `SchemaDiff`, `DatasetDiff`, `DatasetDiffer`;
- keyed exact diff with strict key validity;
- keyless multiset diff preserving duplicates;
- deterministic bounded entries with exact aggregate counts;
- missing-vs-null and schema-diff semantics;
- opt-in value capture only;
- no new mandatory dependency.

## Release posture

V0.3.0 remains frozen. Alpha 1 is an additive API milestone and is the prerequisite for V0.4.0-a2 runtime/report observation.
