# Technical Review — PyIngestKit V0.3.0 Quality & Formats Release

## Decision

V0.3.0 is the stable Quality & Formats milestone following the V0.2.0 Acquisition Release.

## What is frozen

The release stabilizes quality contracts, deterministic profiling, quality-report artifacts, NDJSON, XLSX and Parquet structural parsing, and the six-job reference suite. Existing V0.2 HTTP/retry/provenance semantics remain unchanged.

## Dependency policy

The core runtime remains free of dataframe dependencies. OpenPyXL and PyArrow are optional extras, imported only at their adapter boundaries. The release distribution smoke test installs both extras from the built wheel before executing format reference jobs.

## Operational evidence

The source package includes unit, contract and integration tests for all stable surfaces, including an actual OpenPyXL reference slice and a PyArrow round-trip/reference slice whenever the optional dependency is installed. The GitHub/consumer release gate is expected to execute `make release-check` with all declared development extras available.

## Forward boundary

V0.4 may now focus on Diff / Replay / Versioning. It should consume the stable Dataset/quality contracts rather than reopening V0.3 parser semantics without a compatibility reason.
