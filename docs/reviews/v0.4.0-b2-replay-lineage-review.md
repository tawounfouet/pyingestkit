# Technical Review — V0.4.0-b2 Replay From RAW + Lineage

B2 adds `ReplayContext`, `ReplayRawArtifact`, `ReplayResult`, `ReplayService`, strict HTTP/local RAW replay, SHA-256 integrity checking, additive replay/reproducibility metadata, replay manifest lineage, `REPLAY_*` events, and the `pyingest replay` command. Replay does not silently reacquire external data and does not restore secret values from historical metadata.
