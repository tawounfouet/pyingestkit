# Technical Review — V0.4.0-b1 Dataset Snapshots + Version Registry + PublishedDataset

B1 adds typed JSON round-trip snapshots, content-addressed immutable Dataset versions, a filesystem version store, atomic published pointers, additive metadata capabilities/tables, and `pyingest versions` / `pyingest published`. It does not add SQL data targets, retention, branches, distributed locks, rollback UX, or replay.
