# V0.4.0 — Diff / Replay / Versioning stable release review

## Promotion decision

V0.4.0 is a hardening-only promotion of the qualified V0.4.0-rc1 behavior. No new runtime feature is added.

## Frozen contracts

- public top-level API checked by `scripts/check_public_api.py`;
- CLI command surface checked by contract tests;
- canonical Dataset fingerprint codec version `1`;
- Dataset snapshot version `"1"`;
- diff report version `"1"`;
- content-addressed Dataset version semantics;
- atomic `PublishedDataset` pointer semantics;
- strict replay from historical immutable RAW with lineage and fingerprint verification.

## Release proof

The stable wheel-smoke installs framework/demo wheels into a clean environment, imports real OpenPyXL and PyArrow, discovers seven jobs, reruns the six inherited reference jobs, then proves V1 -> V2 -> diff -> publish -> strict RAW replay through `demo.versioned_ndjson`.

## Non-regression

The release retains additive SQLite/PostgreSQL metadata evolution, optional capability compatibility for custom MetadataStore implementations, and the V0.1-V0.3 public behavior covered by the existing tests.

## Out of scope

No V0.5 target/load capability, scheduler, streaming engine, CDC, data branching or warehouse adapter is part of this promotion.
