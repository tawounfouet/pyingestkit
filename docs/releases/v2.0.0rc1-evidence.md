## Contract freeze

The 2.0 root is frozen to:

```text
ArtifactReference
DatasetVersion
DatasetVersionReference
IngestionDefinition
IngestionResult
IngestionRun
IngestionRunId
IngestionRuntime
PublishedDataset
ResourceReference
Source
```

Legacy V1 execution aliases are intentionally excluded.

The canonical execution method is:

```text
IngestionRuntime.run(
    definition,
    *,
    validation_rules=(),
    publish=False,
    ingestion_run_id=None,
    correlation=None,
)
```

Stable provider/persistence Protocols are frozen through
`tests/contract/fixtures/release_candidate_v2.json` and
`scripts/check_v2_rc.py`.

## Packaging freeze

Base runtime dependencies are limited to the dependency-neutral configuration /
contract layer. Provider libraries remain optional.

Qualified extras include:

```text
http
postgres
s3
excel
parquet
```

The RC build produces and clean-installs both:

```text
pyingestkit-2.0.0rc1-py3-none-any.whl
pyingestkit-2.0.0rc1.tar.gz
```

CI additionally emits `SHA256SUMS-v2.0.0rc1` for distribution evidence.

## Migration and historical line

The V1 stable contract remains sealed on tag `v1.0.0` and is checked separately
from the current 2.0 package.

V1 semantic migration is explicit under `pyingestkit.migration`. The 2.0 RC does
not restore V1 root aliases and does not execute legacy plugins as a migration
shortcut.

## Promotion rule

After this RC is merged, only blocker fixes may be accepted before `2.0.0`.
Any redesign of the frozen root, stable Protocol signatures, durable serialization
contracts or provider-neutral boundary requires a new release candidate.
