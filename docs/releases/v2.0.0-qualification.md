## Publication procedure

After the stable PR is merged, the exact merge SHA must pass post-merge CI,
Security and Docs. Only then may the annotated `v2.0.0` tag and GitHub stable
release be created.

No architectural redesign is allowed in LOT-22. A change to the frozen public
contract requires returning to a new RC.
