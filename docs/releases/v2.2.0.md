# PyIngestKit 2.2.0

## Status

**Stable — LOT-37.**

PyIngestKit 2.2.0 consolidates seven engineering and governance lots (LOT-31 to LOT-37) while preserving the exact 2.0 package root (`len(__all__) == 11`), provider Protocols, and 2.1 lifecycle governance contracts unchanged.

## What 2.2 adds

- **CLI `pik` & Autodiagnostics (LOT-31)**: Standard library CLI (`pyingestkit.cli`), typed POSIX exit codes (`PikExitCode`), `pik doctor` runtime health checks, isolation and automated diagnostic formatting.
- **Root Hygiene & Workspace Isolation (LOT-32)**: Clean local environment isolation, dedicated `infra/` stack and elimination of transient artifacts.
- **Official Brand Identity (LOT-33)**: Official SVG/PNG logos, favicons, modern design tokens in MkDocs Material, and unified documentation styling.
- **Secure OIDC Trusted Publishing (LOT-34)**: GitHub Actions cryptographic workflow with Sigstore attestations, CycloneDX SBOM, SHA-256 checksums, and public consumer smoke verification.
- **Strict Replay Traceability (LOT-35)**: Reconstructed run identity, `StrictReplaySession`, and lineage retention without silent source reacquisition.
- **PostgreSQL Staging, UPSERT & MERGE (LOT-36)**: `PostgresTargetV2` staging table pattern (`ON COMMIT DROP`), streaming `COPY FROM STDIN` throughput, atomic conflict resolution (`DO NOTHING` / `DO UPDATE`), and idempotency short-circuit.
- **Hardened HTTP Acquisition & OAuth 2.0 (LOT-37)**: Stdlib anti-SSRF shield, socket-anchored TCP DNS rebinding defense, full OAuth 2.0 token lifecycle (Client Credentials & Refresh Token), `POST`/`PUT` with arbitrary payloads, CSPRNG Full Jitter retries, and network uncertainty qualification.

## Preserved Baselines

- **Frozen 2.0 Root**: `ArtifactReference`, `DatasetVersion`, `DatasetVersionReference`, `IngestionDefinition`, `IngestionResult`, `IngestionRun`, `IngestionRunId`, `IngestionRuntime`, `PublishedDataset`, `ResourceReference`, `Source` (11 symbols).
- **Additive 2.1 Governance**: `pyingestkit.governance`, `retention`, and `rollback` namespaces remain intact.
- **Minimal Core Dependencies**: Zero mandatory third-party dependencies in the core framework package.

## Provider Qualification

See [Provider Compatibility Matrix](../reference/provider-compatibility-v2.md) for the 2.x support matrix.

2.2 stable qualification covers:
- Core (Acquisition, Decoding, Validation, Versioning, Publication, Replay, CLI)
- Optional `[http]` with Anti-SSRF, DNS Rebinding defense and OAuth 2.0
- Optional `[postgres]` with COPY FROM STDIN, Staging table and UPSERT/MERGE
- Optional `[s3]` with S3ConditionalDatasetPublisher and S3 CAS
- Cross-provider crash/restart recovery and clean base wheel/sdist distributions.
